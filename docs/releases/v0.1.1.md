修复 `v0.1.0` 的窗口按钮与播放界面返回失效问题，适用于 **Windows 10/11 x64**。

### 修复

- 打开“正在播放”后，最小化、最大化/还原、关闭按钮恢复响应鼠标点击。
- “‹ 收起”可以正常返回主界面，`Esc` 继续可用。
- 播放详情的模糊背景和布局元素不再成为 Windows 原生拖动区域；拖动窗口请使用顶部标题栏。

问题来自无边框窗口的 `-webkit-app-region: drag`：播放页面及向外扩展的模糊背景继承了拖动属性，原生命中区域截获了按钮的鼠标输入。普通 Playwright 点击绕过这层命中逻辑，因此旧回归没有发现。此次新增打包拖动区域检查、按钮状态检查，并在 Windows 实际鼠标下验证。

### 下载与升级

- `BiliBiliMusic-Setup-0.1.1.exe`：安装版，可更新现有安装。
- `BiliBiliMusic-Portable-0.1.1.exe`：免安装启动。
- `SHA256SUMS.txt`：两个 exe 的 SHA-256 校验值。

先从旧版托盘菜单选择“退出”，再运行新版。队列、收藏夹、喜欢列表仍使用 `%APPDATA%\bilibili-music\state.json`，升级前可退出应用并备份。关闭按钮仍表示收进托盘，完全退出请使用托盘菜单。

### 验证与限制

- 模块与属性测试、类型检查、生产构建。
- 打包程序中的拖动区域、最大化/还原、最小化、关闭到托盘、返回和退出保存回归。
- Windows 原生鼠标点击复核，覆盖普通窗口、最小尺寸、最大化状态和标题栏双击。

仍为测试版，暂无代码签名和自动更新。接口风控、真实网络、系统媒体键、多显示器与长时间播放的限制沿用 `v0.1.0`；本次修复不改变 Electron 的体积和缓存成本。源码采用 MIT。
